# Отчёт: пять систем на корпусе диалогов (по имеющимся данным)

Дата: 2026-11-17 · модель Qwen3.5-4B (bf16, ROCm), greedy, до 32 новых токенов ·
код: main с фиксом маски kvinject (`68add5b`) · протокол: warmup + 5 чередующихся
повторов латентности, e2e включая embedding/retrieval · статус: промежуточный
(latent-v1 — 4/12 диалогов, shared-* — 1 диалог).

Системы: **живая память** = K/V-инъекция из CorrectionLayer без RAG (`v4_kv_mid`);
**RAG на живой памяти** = те же слоты банка как эмбеддинги RAG (три формы);
**пирамида** = PyramidKV-128; **классический RAG** = текстовый банк, last-слой;
**RAG на средних слоях** = текстовый банк, mid-слой (`rag_latent_mid`).

## 3. Статистика (paired bootstrap по диалогам, 4 диалога)

- RAG-средние vs классический RAG: **p < 0.0001** (направление 4/4) — ключи
  mid-слоя дают устойчивый прирост.
- RAG-средние vs полный контекст: p = 0.75 — **паритет с gold** при в 4.5×
  меньших prompt-токенах и −28 % VRAM.
- Живая память vs пирамида: **p = 0.80 — паритет качества**; при этом e2e
  −20 %, prompt 5× меньше, VRAM −27 %. Единственная ось пирамиды — attn-слоты
  (в 3.1× меньше): арифметика attention, нерелевантная в bandwidth-bound декоде.
- Живая память/RAG vs полный контекст: p < 0.0001 — gold недосягаем без текстового
  канала.

## 4. Дополнительные метрики (4 диалога)

- Тон (cos к банку реплик): 0.804–0.829 — узкий диапазон, условия почти не
  различает; лучше у текстовых RAG (0.821–0.829), хуже у живой памяти/пирамиды.
- Stale на обновлённых фактах: жив память 0.000 (лучшая), полный контекст 0.100,
  RAG-средние 0.400 (худшая — оговорка малых счётчиков).
- Честный unanswerable (доля истинных отказов): 0.38–0.75; классический RAG и
  живая память 0.75, RAG-средние 0.38 (n=8, только ориентир).

Кластерное центрирование (anchor = доминантный слот, deviation-ключи) улучшает
слот-ключи +0.084, но не дотягивает до ключей-реплик; комбинация с инъекцией
обваливается ниже каждого компонента — общий банк искажает ключи своей выдачей.
Размер банка живой памяти почти не влияет: 128 ≈ 512 > 1024.

## 6. Выводы

1. **RAG на средних слоях — лучшая система ветки**: паритет с полным контекстом
   (p=0.75) при 4.5× меньших prompt-токенах, −28 % VRAM и −28 % e2e-латентности;
   устойчиво лучше классического RAG (p < 0.0001).
   **Prior art**: эффект «mid > last» опубликован — Layer by Layer
   (Skean et al., ICML 2025, arXiv:2502.02013, 32 MTEB-задачи) и KV-Embedding
   (Tang et al., 2026, arXiv:2601.01046, training-free, выбор слоя); см. также
   SRSD (EMNLP Findings 2026) в docs/RELATED_WORK.md. Наш результат —
   воспроизведение на диалоговых fact-пробах, не новизна.
2. **Живая память без RAG — рабочая альтернатива пирамиде**: паритет recall
   (p=0.80) при −20 % латентности, 5× меньших токенов промпта и −27 % VRAM;
   обмен «×3 арифметики attention за ×5 трафика памяти» выгоден в bandwidth-bound
   режиме; малый банка (128 слотов) достаточен.
3. **RAG на живой памяти не работает**: лучшая форма (кластерные ключи) хуже
   ключей-реплик; совместное использование банка для инъекции и ключей
   саморазрушительно (0.528). Банк хранит темы, не факты.
4. **Классический RAG** — прочная базовая линия (0.775), дешевле золота в 4.5×;
   его mid-слойная версия доминирует.

## 7. Оговорки

n=4 для §1–§4 (широкие ДИ; значимость только грубых эффектов), n=1 для §5.
Recall — keyword-скоринг; unanswerable-метрика завышена (см. аудит); тон —
косинусный прокси. Догон корпуса (latent-v1 8 батчей, shared-dev-v1 11 батчей)
уточнит числа — этот отчёт обновляется по мере поступления данных.
